# Security policy

LeadOps OSS handles workflows that can include personal information and external side effects. Treat security issues seriously.

## Reporting a vulnerability

Please do **not** publish exploit details or real customer data in a public issue. Use GitHub's private vulnerability reporting feature when available for this repository. If private reporting is unavailable, open a minimal issue asking for a private contact channel without disclosing the vulnerability.

## Supported versions

The project is pre-1.0. Security fixes target the latest `main` branch and the latest tagged release when releases exist.

## Production warning

The v0.1 in-memory reference server is not presented as production-complete. Authentication, durable encrypted persistence, provider signature verification, audit logs and rate limiting are explicit roadmap items.
